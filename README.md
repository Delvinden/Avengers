# SJCET First Years — Class Wall

Every card on this wall was shipped through a pull request, exactly the way software teams work in industry.

## Add your team's card (about 10 minutes)

1. Open the **`_teams`** folder in this repository.
2. Click **Add file → Create new file**.
3. Name the file `team-yourteamname.md` (lowercase, no spaces), for example `team-bytebusters.md`.
4. Copy the template below into the file and fill in your details. Keep the `---` lines exactly as they are.
5. Click **Commit changes…**, then **Propose changes**.
6. On the next screen, click **Create pull request**.
7. In the pull request description, write your change as a user story:
   *"As a first-year, I want our team card on the class wall so that…"*
8. Click **Create pull request** again. Done! Your card goes live once it is reviewed and merged.

### Template

```
---
team: "Your team name"
members: "First names only, separated by commas"
dream_project: "One app or project you would love to build"
fun_fact: "One fun fact about your team"
colour: "your favourite colour, e.g. orange"
---
```

## Review another team

Open the **Pull requests** tab, pick another team's pull request, go to **Files changed**, and leave one friendly comment.

## Rules

- First names only. No phone numbers, emails or surnames.
- Keep it friendly. Every card is visible to the whole class.
